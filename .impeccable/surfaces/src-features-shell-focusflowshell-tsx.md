## Direction contract

Mode: Operate. Scope: plugin workspace, all pages, desktop and mobile.

**THESIS:** A writing workspace for deliberate work: titles and next actions lead; forms unfold on demand.

**OWN-WORLD:** Host surfaces and interface font, compact rounded controls, quiet dividers, restrained accent for selection and action; no display mastheads.

**STORY:** Plan selects the Sprint, Focus moves its Tasks, History reviews the outcomes. Navigate in one click; unfold context only when needed.

**FIRST VIEWPORT:** Four compact destinations above a modest Sprint title and date. A Jira-like kanban has shared status columns and horizontal Story swimlanes: Story heading, its Task cards, then the next Story. Each Story has an icon-only create action opening a focused popup. Compact panels show a selected status with the same Story grouping. Plan stacks Sprint, Month backlog, and Epic backlog vertically, with compact folded rows and item menus aligned on the right. Draft creation is explicit; Story locations inside Epics link to their planning queue. Active Sprint membership changes confirm in one dialog for both buttons and drag-and-drop, including empty drop zones. History shows one selected Sprint/Month/Quarter/Year report, a thin compact outcome ring, ranked Effective Tag bars, and completion charts. Narrow panels replace plot axes with readable horizontal bars. Reflections quote the user's actual notes; raw evidence and Sprint exploration stay folded. Review Cycles remain 4/12/48 commitments, with partial and filtered coverage explicit. History navigation uses adjacent-period arrows and a searchable year/month archive, retaining context across report levels. Dates stay in detailed evidence, not identity. Filters are one direct icon opening a compact single-search Epic/tag picker with removable chips on the report. Evidence is a compact scope table; Wins/Friction/Improvements are distinct reading blocks. A quiet gear opens Settings directly; its heading and rows share one measure. Focus uses a quiet searchable Story-filter trigger and one-click clear, never a wide native dropdown. Settings use value-only WIP rows with focused policy editors, seven weekday buttons, and a vault-scoped folder/file browser. Moving and switching workspaces remain separate confirmed operations. Workspace move confirmation lives in the folder picker itself: Folder name, Destination, consequences, then Move folder; no second move popup.

**FORM:** Writing-app workspace, candidate five, seed `da24414e`. Signature: fold a row into its working detail, 160ms reveal with reduced-motion support.

Latest user refinements: compact tags follow titles and wrap on narrow rows;
Month/Epic counts are small circles. Task menus stay right-aligned. Inbox uses
one create icon and a typed title/tag dialog; Candidate edit and recoverable
Distraction trash live in row menus. Story/Epic Edit shares typed title, own tags,
and Acceptance Criteria, with inherited tags read-only and Markdown preserved.
Review Sprint has five icon-led steps, a one-Story-at-a-time Outcomes workspace,
conditional Task fields, and lists of multiline Markdown reflection items.
Named next actions replace Previous/Continue. Story outcomes is stated explicitly
in the close checklist. Page titles share a top alignment; the Loaded preview
supports Epic, Story, and Task reorder through the same planning service.

Final user-directed additions: canonical Markdown fields in forms (Candidate:
Description and Entry Review; Epic: Intent; Story/Task: Description). All work
types use separate checkbox criteria with multiline Markdown item editors.
Candidate acceptance reviews the target type’s fields before converting the
same note, preserving Entry Review and unrelated content. Inbox rows no longer
expand: a short description or rejection reason and a quiet date are visible.
Month is now an explicit shortlist: new Stories start within their Epic, + Month
selects them, and Return to Epic removes Month selection. Existing Month work
is preserved. There is still only one Draft or Active Sprint, explained in Plan.
Active Sprint timing counts from the actual start; the planned week is secondary.
Tag reporting switches Tasks / Stories / Epics with distinct units and honest
frozen-effective versus current-Epic-tag attribution. Tag suggestions overlay
the form rather than changing its height.
