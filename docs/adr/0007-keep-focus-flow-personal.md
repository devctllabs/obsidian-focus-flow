# Keep Focus Flow personal

Focus Flow is permanently a single-operator system. Vault sync may replicate one person's notes across devices, but the domain will not introduce teams, assignees, shared ownership, permissions, or realtime collaboration semantics. This keeps Mission, priority, commitment, WIP, and reflection attributable to one decision-maker instead of turning a personal practice into a lightweight project-management service.

## Considered options

- **Leave a path to teams** would add ownership and authorization concepts to every entity before any personal workflow needs them.
- **Add collaboration later without changing the model** would hide genuinely different conflict, identity, and accountability semantics behind fields designed for one person.

## Consequences

A collaborative product would require a new domain decision and migration rather than optional fields on the personal model. File conflicts created by sync remain external consistency events, not concurrent multi-user editing.
